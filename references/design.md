# 蓝白学术视觉

固定倾向：白底、蓝色页眉、章节编号，无独立页码、无动画/切换。中文微软雅黑，正文左对齐自然字距，黑/深灰、少量红/加粗。背景方法自然主题标题，结果按需要用有据发现。

## 使用实际版式库

`assets/reference-layouts.pptx`包含五张原生可编辑空模板；`assets/layout-catalog.json`列出页型与原稿来源；`assets/layouts.mjs`提供同一套原生对象的Artifact Tool实现，不需要重新猜测布局。其他作者工具应从空模板选页并填充内容，保留几何与样式。模板不包含原论文结果、原图或校徽，不能拿占位文字当成品。

| 页型 | 应保留的关系 |
|---|---|
| cover | 大面积蓝色上部、弧形下边界、白色标题、下部白色信息区；身份按任务替换或隐藏 |
| contents | 左侧约37.34%整块蓝底及白色目录/CONTENTS；右侧蓝色编号块、圆角章节条、阴影；按实际章节数调整，不换成普通列表 |
| body-figure | 蓝色编号页眉；原图与说明依内容组织；有小结时使用底部浅蓝条、蓝色结论标签与少量红色强调 |
| summary | 蓝色编号主题块与浅蓝说明区逐行对应；按真实结论数量调整行数行高，不为四行凑内容；放不下先建议拆页；底部概括不得新增学术判断 |
| closing | 蓝页眉、嵌套圆角浅色分区、居中结束文字；具体结尾结构和措辞按汇报目的确认 |

将每页`layout_id`记在大纲/工作计划中；图文分栏、双图、多图、流程、表格是正文变体，保留共同页眉与所选结论条样式。版式库之外的结构变化先提案。校准阶段覆盖五种页型；日常代表页仍按内容难度选3—5张，已确认的同一模板不重复试出多套。

assets/style.json与新模板中的字号/间距是待本轮样页认可的起点。参考稿960×540pt；模块使用1280×720 CSS px，字号与坐标换算为pt时乘0.75，不能混用。页型不同，不机械按同一页眉高度压正文。

## 代表页比较

大纲通过后建议3—5张不同内容/难度页面清单；用户确认后第一轮各做一张。用户指定需要第二种排法的页面后再补第二版，不给所有页自动做变体。字号、行距、页内边距、间距、图文比例、主次与留白随内容确认，不预设全篇紧凑/疏朗。

两组待选择效果：页眉“编号+章节名，正文另放当页主题”或“编号+当页主题”；接近原稿的浅色圆角分区/轻阴影或减少框线阴影的清爽效果。可以先提供一种合适方案，用户指定页再比较，不把所有变量做成组合爆炸。

## 页面关系

单主图+解释、双图对照、图文混排、原生简明流程、可编辑表格、自然文字页是可用结构，不是固定页序。图对齐遵从比较关系；有主次就不强做等大。图件保持比例，不拉伸、不隐式cover裁切。流程线承载原文确有关系，不虚构环节。

圆角分区和结论条按需；不机械套等高三卡片、固定四字词、装饰图标。原图无关时允许文字页，不为图多找无关配图。拥挤先调关系/间距或提拆页建议；实质删减仍由用户定，不不断缩字。

放置图片前读取实际宽高，以contain计算真实对象宽高并居中；不要仅设置fit后把任意框宽高写入导出的原生图片对象。模块要求直接传入原图字节(blob)与真实宽高，避免非ASCII路径在某些作者工具中生成失效图片。导出后核对嵌入图片与原图哈希；先自动检查对象比例和媒体完整性，发现问题先修正，再首次渲染，避免整稿导出后才发现拉伸或丢图。

图题必要时图下、表题表上，简短可编辑，不额外加作者年份；不照搬论文图号，多图(a)(b)先建议。校徽单位是可替换/隐藏的身份素材，不烘焙在通用背景；封面身份、导师、专业、日期当次确认。默认目录，过渡、备份、结尾按需提案选择。
